# M5-07 — Tests + Research Evidence Export

## Purpose
Make the M5 research layer testable, auditable, and exportable for research analysis.

Core question:
> Can the evidence generated by BisaBelajar be extracted in a reproducible way without losing provenance?

## Inputs
Use M5-01 through M5-06 outputs.

## Export principle
Export should preserve research traceability.

Minimum conceptual chain:
```text
Learner
 ↓
Context
 ↓
Activity
 ↓
LearningEvent
 ↓
ValidatedEvidence
 ↓
LearningState
 ↓
WeakArea
 ↓
Intervention
 ↓
Reassessment
 ↓
NextLearningAction
 ↓
ObservedOutcome
```

Not every record will contain every element. Missing relationships must remain explicit rather than fabricated.

## Export format
Prefer a practical research-friendly format such as CSV/JSON, based on existing project conventions.

If multiple datasets are needed, separate logical entities rather than flattening everything into an unreadable table.

Possible datasets:
- learners/research identifiers
- activities/context
- learning events
- validated evidence
- learning states
- trajectories
- weak areas
- interventions
- reassessments
- outcomes

## Reproducibility
Export must include:
- timestamps
- IDs/provenance
- relevant context
- evidence quality/confidence
- task demand
- decision/inference rules where applicable
- version/metadata when available

## Privacy
Do not export unnecessary personal information.

Prefer research identifiers/pseudonyms where the architecture supports them.

## Tests
Test:
- export completeness
- provenance
- chronological consistency
- relationship integrity
- missing optional fields
- context preservation
- evidence quality preservation
- reproducibility
- privacy filtering
- deterministic output where appropriate

Run full regression:
- M5-01
- M5-02
- M5-03
- M5-04
- M5-05
- M5-06
- M4-T06
- M4-T05
- M4-T04
- M4-T03
- M4-T02
- M3

## Scope fence
Do NOT:
- alter M4 inference/intervention rules
- add ML
- add causal inference
- generate research conclusions automatically
- generate paper text automatically
- fabricate missing research data

No commit. No push.

## Final M5 acceptance
M5 is complete when:
- evidence is traceable
- state history is preserved
- trajectories are available
- weak areas are identifiable
- competency-aligned reassessment is supported
- intervention response/improvement can be observed
- context variation can be analyzed
- research evidence can be exported
- tests pass
- M3/M4 regression passes

## STOP
Produce final report and wait for human review.
