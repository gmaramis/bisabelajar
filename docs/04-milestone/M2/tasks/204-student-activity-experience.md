# TASK-204 — Student Activity Experience

**Status:** REVIEW

## Objective
Provide a consistent student-facing Activity experience.

## Flow
Learning Unit → Activity List → Activity Detail → Start

## Requirements
- Published activities displayed in order.
- Activity type displayed.
- Student-safe instructions/metadata displayed.
- Enrollment and authorization enforced.
- Activity start state recorded.

## Out of Scope
Grading, mastery, NEXUS, code execution.

## Acceptance Criteria
- Student sees published activities.
- Student can open accessible activities.
- Draft/archived activities are inaccessible.
- Start state persists.
- Focused and full tests pass.
